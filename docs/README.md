`en/reference.md` is a copy of the file the plugin writes to `plugins/CelestiRift/docs/` on
every reload. Refresh it after adding mechanics: run `./gradlew :celestirift-core:smokeTest`
and copy `celestirift-core/build/smoke-server/plugins/CelestiRift/docs/reference.md`.
The single-page web version is built with `node tools/build-docs-page.mjs`.
